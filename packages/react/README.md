# @trellis-ui-pack/react

Accessible React components built on React Aria and Tailwind CSS v4.

```bash
npm install @trellis-ui-pack/react react react-dom tailwindcss
```

Import Tailwind and the component styles in your application stylesheet:

```css
@import "tailwindcss";
@import "@trellis-ui-pack/react/styles.css";
```

```tsx
import { Button } from '@trellis-ui-pack/react';

export function SaveButton() {
  return <Button>Save</Button>;
}
```

---
title: Theming
description: Re-theme Trellis with CSS variables.
---

All design tokens are CSS variables defined in `@trellis-ui/styles` and exposed to Tailwind through `@theme inline`.
You can use them in your own markup too: `bg-primary`, `text-muted-foreground`, `border-border`, `rounded-tr`…

Override any variable after importing the styles:

```css title="app/globals.css"
@import "tailwindcss";
@import "@trellis-ui/react/styles.css";

:root {
  --tr-primary: oklch(0.55 0.2 265);
  --tr-primary-hover: oklch(0.5 0.2 265);
  --tr-primary-soft: oklch(0.95 0.04 265);
  --tr-ring: oklch(0.55 0.2 265 / 0.45);
  --tr-radius: 0.375rem;
}

.dark {
  --tr-primary: oklch(0.7 0.17 265);
}
```

## Tokens

| Variable | Tailwind utility | Purpose |
| --- | --- | --- |
| `--tr-background` / `--tr-foreground` | `bg-background`, `text-foreground` | Page colors |
| `--tr-surface` | `bg-surface` | Cards and raised surfaces |
| `--tr-muted` / `--tr-muted-foreground` | `bg-muted`, `text-muted-foreground` | Subtle backgrounds and secondary text |
| `--tr-border` / `--tr-input` | `border-border`, `border-input` | Dividers and form control borders |
| `--tr-primary` (+ `-hover`, `-soft`, `-foreground`) | `bg-primary`… | Brand color |
| `--tr-danger` (+ `-hover`, `-soft`, `-foreground`) | `bg-danger`… | Destructive actions and errors |
| `--tr-warning` (+ `-soft`, `-foreground`) | `bg-warning`… | Warnings |
| `--tr-ring` | `ring-ring` | Focus ring |
| `--tr-radius` | `rounded-tr` | Base corner radius |

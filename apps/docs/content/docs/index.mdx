Trellis is a React component library built on [React Aria Components](https://react-spectrum.adobe.com/react-aria/) and Tailwind CSS v4.
What sets it apart is the form layer: `@trellis-ui-pack/form` connects every input to React Hook Form and Zod, so validation, error messages
and accessibility attributes are wired for you — with full TypeScript inference from your schema.

<ComponentPreview name="form-signup" />

## Packages

| Package | What it contains |
| --- | --- |
| `@trellis-ui-pack/react` | UI components (Button, TextField, Select, Dialog…) |
| `@trellis-ui-pack/form` | `useZodForm`, `<Form>` and `Form*` fields for React Hook Form + Zod |
| `@trellis-ui-pack/markdown` | Streaming-friendly Markdown and code blocks for AI chats |
| `@trellis-ui-pack/charts` | Themed line, area, bar and donut charts |
| `@trellis-ui-pack/styles` | Design tokens (installed automatically with `@trellis-ui-pack/react`) |

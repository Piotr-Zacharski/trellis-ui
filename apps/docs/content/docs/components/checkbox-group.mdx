## Import

```tsx
import { Checkbox, CheckboxGroup } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormCheckboxGroup` from `@trellis-ui-pack/form` – same props plus `name` and `control`:

```tsx
<FormCheckboxGroup control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

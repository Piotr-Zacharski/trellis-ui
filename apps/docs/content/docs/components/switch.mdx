## Import

```tsx
import { Switch } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormSwitch` from `@trellis-ui/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormSwitch control={form.control} name="fieldName" label="Label" />
```

## Import

```tsx
import { Rating } from '@trellis-ui/react';
```

Built on a radio group: arrow keys change the value and screen readers announce “3 of 5 stars”.

## With React Hook Form

Use `FormRating` from `@trellis-ui/form` – same props plus `name` and `control`:

```tsx
<FormRating control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

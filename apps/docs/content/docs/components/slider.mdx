## Import

```tsx
import { Slider } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormSlider` from `@trellis-ui-pack/form` – same props plus `name` and `control`:

```tsx
<FormSlider control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

## Import

```tsx
import {
  Form,
  FormCheckbox,
  FormNumberField,
  FormRadioGroup,
  FormSelect,
  FormSwitch,
  FormTextAreaField,
  FormTextField,
  SubmitButton,
  useZodForm,
} from '@trellis-ui/form';
```

Read the [Forms guide](/docs/forms) for type-safe field names, async submit and server errors.

## Dates, combobox and toasts

`FormDatePicker` maps `z.date()` to a calendar, `FormComboBox` stores the selected item's id, and `toast` confirms the submit.

## Every field type

OTP, date range, time, segmented control, slider, checkbox group, tags, color, file upload and rating – all with Zod validation.

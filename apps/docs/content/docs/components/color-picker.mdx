## Import

```tsx
import { ColorPicker } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormColorPicker` from `@trellis-ui/form` – same props plus `name` and `control`:

```tsx
<FormColorPicker control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

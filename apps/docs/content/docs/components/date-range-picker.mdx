## Import

```tsx
import { DateRangePicker, RangeCalendar } from '@trellis-ui/react';
```

With `FormDateRangePicker` the form value is `{ start: Date, end: Date }` – validate it with `z.object({ start: z.date(), end: z.date() })`.

## With React Hook Form

Use `FormDateRangePicker` from `@trellis-ui/form` – same props plus `name` and `control`:

```tsx
<FormDateRangePicker control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

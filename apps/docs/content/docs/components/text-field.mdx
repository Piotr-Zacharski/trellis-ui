## Input group

Put icons, prefixes, units or buttons inside the field with `startContent` and `endContent`.

<ComponentPreview name="input-group" />

## Import

```tsx
import { TextField } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormTextField` from `@trellis-ui/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormTextField control={form.control} name="fieldName" label="Label" />
```

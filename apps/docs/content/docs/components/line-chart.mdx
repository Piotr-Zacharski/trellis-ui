## Import

```tsx
import { LineChart } from '@trellis-ui-pack/charts';
```

Charts live in their own package, built on [Recharts](https://recharts.org) and themed with the `--tr-chart-1…5` tokens:

```npm
npm i @trellis-ui-pack/charts
```

Add `@import "@trellis-ui-pack/charts/styles.css";` to your CSS.

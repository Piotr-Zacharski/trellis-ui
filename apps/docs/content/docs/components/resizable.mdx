## Import

```tsx
import { ResizablePanels } from '@trellis-ui-pack/react';
```

Dividers are keyboard accessible: focus one and use the arrow keys (<kbd>Shift</kbd> for bigger steps), <kbd>Home</kbd> and <kbd>End</kbd>.

## Import

```tsx
import { ComboBox, ComboBoxItem } from '@trellis-ui/react';
```

## With React Hook Form

`FormComboBox` from `@trellis-ui/form` stores the selected item's `id` in the form.

```tsx
<FormComboBox control={form.control} name="city" label="City" items={cities}>
  {(item) => <ComboBoxItem id={item.id}>{item.name}</ComboBoxItem>}
</FormComboBox>
```

See the full example on the [Date Picker](/docs/components/date-picker#with-react-hook-form) page.

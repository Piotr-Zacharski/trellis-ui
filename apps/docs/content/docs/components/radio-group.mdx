<ComponentPreview name="radio-group" />

## Import

```tsx
import { Radio, RadioGroup } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormRadioGroup` from `@trellis-ui/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormRadioGroup control={form.control} name="fieldName" label="Label" />
```

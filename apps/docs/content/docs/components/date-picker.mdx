## Import

```tsx
import { Calendar, DatePicker } from '@trellis-ui-pack/react';
```

Dates are values from [`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/) (installed with Trellis),
so they are timezone-safe and respect the user's locale and calendar system.

```tsx
import { getLocalTimeZone, parseDate, today } from '@internationalized/date';

<DatePicker label="Start" defaultValue={parseDate('2026-11-02')} minValue={today(getLocalTimeZone())} />;
```

## Import

```tsx
import { Select, SelectItem } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormSelect` from `@trellis-ui/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormSelect control={form.control} name="fieldName" label="Label" />
```

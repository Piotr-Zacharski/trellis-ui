## Import

```tsx
import { DonutChart } from '@trellis-ui/charts';
```

Charts live in their own package, built on [Recharts](https://recharts.org) and themed with the `--tr-chart-1…5` tokens:

```npm
npm i @trellis-ui/charts
```

Add `@import "@trellis-ui/charts/styles.css";` to your CSS.

## Import

```tsx
import { Markdown } from '@trellis-ui/markdown';
```

Lives in its own package so the core stays dependency-free:

```npm
npm i @trellis-ui/markdown
```

Add `@import "@trellis-ui/markdown/styles.css";` to your CSS. GitHub-flavoured Markdown (tables, task lists) is supported; raw HTML is ignored for safety.

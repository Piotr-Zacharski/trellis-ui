## Import

```tsx
import { DateField, TimeField } from '@trellis-ui-pack/react';
```

`FormDateField` stores a `Date`; `FormTimeField` stores an `HH:mm` string, which pairs with `z.iso.time()`.

## With React Hook Form

Use `FormTimeField` from `@trellis-ui-pack/form` – same props plus `name` and `control`:

```tsx
<FormTimeField control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

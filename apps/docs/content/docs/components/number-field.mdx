## Import

```tsx
import { NumberField } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormNumberField` from `@trellis-ui-pack/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormNumberField control={form.control} name="fieldName" label="Label" />
```

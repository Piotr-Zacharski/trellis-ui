## Import

```tsx
import { Checkbox } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormCheckbox` from `@trellis-ui-pack/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormCheckbox control={form.control} name="fieldName" label="Label" />
```

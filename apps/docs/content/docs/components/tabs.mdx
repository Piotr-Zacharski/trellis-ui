## Import

```tsx
import { Tab, TabList, TabPanel, Tabs } from '@trellis-ui-pack/react';
```

Tabs are fully keyboard accessible: arrow keys move between tabs, <kbd>Home</kbd> / <kbd>End</kbd> jump to the first and last tab.

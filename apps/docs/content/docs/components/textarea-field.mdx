## Import

```tsx
import { TextAreaField } from '@trellis-ui/react';
```

## With React Hook Form

Use `FormTextAreaField` from `@trellis-ui/form` – it accepts the same props, plus `name` and `control`. See [Forms](/docs/forms).

```tsx
<FormTextAreaField control={form.control} name="fieldName" label="Label" />
```

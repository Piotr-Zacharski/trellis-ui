## Import

```tsx
import { CodeBlock } from '@trellis-ui-pack/markdown';
```

Highlighting uses [sugar-high](https://sugar-high.vercel.app) (~1 kB). Fenced code inside `<Markdown>` renders as a CodeBlock automatically.

## Import

```tsx
import { AppLayout, Navbar, Sidebar, SidebarContent, SidebarFooter, SidebarHeader, SidebarItem, SidebarSection } from '@trellis-ui/react';
```

Below the `md` breakpoint the sidebar moves into a drawer opened by the hamburger button that `Navbar` renders automatically.

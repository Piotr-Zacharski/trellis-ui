## Setup

Mount `<Toaster />` once, near the root of your app:

```tsx title="app/layout.tsx"
import { Toaster } from '@trellis-ui/react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

## Usage

Call `toast` from any client code – event handlers, `onSubmit` of a form, etc.

```tsx
import { toast } from '@trellis-ui/react';

toast('Event has been created');
toast.success('Changes saved', { description: 'Your profile has been updated.' });
toast.warning('Storage almost full');
toast.error('Payment failed', { timeout: 0 }); // stays until closed

const key = toast('Uploading…', { timeout: 0 });
toast.dismiss(key);
```

Toasts are announced to screen readers, pause while hovered or focused, and can be reached with <kbd>F6</kbd>.

<Callout type="warn">
  Toast is built on React Aria's `UNSTABLE_Toast` API, which may still change in minor React Aria releases.
</Callout>

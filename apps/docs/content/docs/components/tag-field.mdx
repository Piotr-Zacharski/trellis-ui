## Import

```tsx
import { Tag, TagField, TagGroup } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormTagField` from `@trellis-ui-pack/form` – same props plus `name` and `control`:

```tsx
<FormTagField control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

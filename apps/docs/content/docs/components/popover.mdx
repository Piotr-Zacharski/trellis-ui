---
title: Popover
description: A popup anchored to its trigger – for menus of settings, extra info or small forms.
---

<ComponentPreview name="popover" />

## Import

```tsx
import { PopoverContent, PopoverTrigger } from '@trellis-ui-pack/react';
```

The first child of `PopoverTrigger` is the trigger (usually a `Button`), the second is the `PopoverContent`.
Focus moves into the popup and returns to the trigger on close; <kbd>Esc</kbd> and outside clicks close it.

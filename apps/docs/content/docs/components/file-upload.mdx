## Import

```tsx
import { FileUpload } from '@trellis-ui-pack/react';
```

## With React Hook Form

Use `FormFileUpload` from `@trellis-ui-pack/form` – same props plus `name` and `control`:

```tsx
<FormFileUpload control={form.control} name="fieldName" label="Label" />
```

The [Form](/docs/components/form) page has an example with every field.

## Import

```tsx
import { AttachmentPreview, ChatInput, ChatMessage, useVoiceRecorder } from '@trellis-ui-pack/react';
```

## Features

- **Auto-growing textarea** – <kbd>Enter</kbd> sends, <kbd>Shift</kbd>+<kbd>Enter</kbd> adds a new line (IME composition is respected).
- **Attachments** – the paperclip button, **drag & drop** onto the box, or **paste** a screenshot. Images get thumbnails, audio an inline player, other files a chip with name and size.
- **Voice messages** – the mic button records with `MediaRecorder` and shows a live level meter and timer. ✓ attaches the recording, the trash icon discards it.
- **Send / stop** – while `isPending` is true the send button turns into a stop button that calls `onStop`.
- **Limits** – `acceptedFileTypes`, `maxAttachments` and `maxFileSize`, with an inline message when a file is rejected.

## Sending to your API

`onSubmit` receives the text and the `File` objects. If it returns a promise, the input is cleared once it resolves.

```tsx
<ChatInput
  isPending={isStreaming}
  onStop={() => abortController.abort()}
  onSubmit={async ({ text, attachments }) => {
    const body = new FormData();
    body.append('text', text);
    for (const a of attachments) body.append('files', a.file);
    await fetch('/api/chat', { method: 'POST', body });
  }}
/>
```

<Callout>
  Every attachment has a `url` (object URL) for previews. After submit the URLs belong to you – call `URL.revokeObjectURL(url)` when
  the message is removed.
</Callout>

## Voice recording on its own

`useVoiceRecorder` powers the mic button and can be used directly:

```tsx
const { status, duration, levels, start, stop, cancel } = useVoiceRecorder();

const file = await stop(); // File (webm / m4a / ogg depending on the browser)
```

Recording requires a secure context (HTTPS or `localhost`) and the user's microphone permission.
